# TaskFlow Pro 🚀

TaskFlow Pro is a modern Kanban-style task management app built with React, TypeScript, and Tailwind CSS. It helps teams organize projects, move work across columns, and keep progress visible in a polished dashboard experience.

## ✨ Highlights

- Kanban board workflow with To Do, In Progress, Review, and Done stages
- Drag-and-drop task updates with accessible interactions
- Project-based organization with dashboard insights
- Persistent local state and dark mode support
- Responsive layout for desktop and tablet use

## 🛠️ Tech Stack

- React 19
- TypeScript
- Vite
- Tailwind CSS
- Zustand
- React Router
- @dnd-kit

## 🚀 Getting Started

```bash
npm install
npm run dev
```

## 📦 Build

```bash
npm run build
```
